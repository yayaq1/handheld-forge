# Harbor Lights (minimal GBDK template)

Original placeholder project for Handheld Game Forge v0.

**Flow:** title card → premise card → lore card → pier play (light three posts).

```bash
export GBDK_DIR=/opt/gbdk   # or run ../../scripts/setup.sh
./build.sh                  # → build/harbor_lights_v0.1.gbc
../../scripts/playtest.py --rom build/harbor_lights_v0.1.gbc --out qa
```

See `BRIEF.md.example` and `art/BAR.handheld.example.md` for Stage A starters.
