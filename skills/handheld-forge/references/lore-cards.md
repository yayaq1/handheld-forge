# Lore cards

Depth over a two-minute loop means **cards with craft**, not only a play loop.

## Card types

1. **Title card** – game name, atmosphere, optional motif
2. **Premise card** – one short hook (what you are doing and why it matters)
3. **Dialogue / lore cards** – before and after key moments: portrait + speaker name/tag + body text
4. **Result / epilogue cards** – after failures or clears

## Text rules

- Dialogue body: about **≤4 lines × ~18 characters** (fit the panel; measure in stills)
- Original paraphrases only – no long verbatim quotes from other works
- En dashes (–) in prose; define a glyph if the font maps `~` or similar
- A advances; START skips; optional auto-advance after typing completes

## Art rules

- Portrait tiles load in chunks while the screen is black (see VRAM notes)
- Readable silhouette at native res; name in accent colour; location tag secondary
- Keep panel chrome consistent across the set (one card system)

## Flow

Title → Premise → (optional how-to) → Lore → Play → Lore beats → Results → Title
